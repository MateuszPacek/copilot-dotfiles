# Glossary

Shared vocabulary. Agents use these terms exactly. New terms are added only with the user's approval.

| Term | Definition | Do not say |
|---|---|---|
| Business requirement (BR) | What the business needs and how success is measured | goal, wish |
| Product requirement (PRD) | What the product does for its users | feature spec |
| Technical requirement (TR) | How the solution must behave technically | design note |
| Gate | An independent check that a layer meets its acceptance criteria before its PR merges up | review, sign-off |
| Staged PR | A pull request from a layer branch into its parent layer branch | child PR |
