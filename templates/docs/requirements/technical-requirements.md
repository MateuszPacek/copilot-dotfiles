# Technical Requirements

Layer 3. Parent: product requirements. Describes how the solution must behave technically so that the product requirements are met.
One requirement per `##` section. IDs are TR-001, TR-002 and so on, and are never reused. Status is draft, approved or deprecated.

## TR-001 <short title>
- **Statement:** The <component> shall ...
- **Parent:** PRD-001
- **Interfaces and constraints:** <inputs, outputs, limits, dependencies>
- **Acceptance criteria:**
  - AC1: <measurable condition with a threshold>
- **Verification level:** Integration test (tag tests with TR-001); unit tests for module detail
- **Status:** draft
