# Product requirements tree

One folder per product or module group, one file per module (template `../templates/prd-module.md`). Numbers are fixed once assigned: a new module takes the next free number in its folder, and a removed number is retired, never reused. Files are created only when work on that module starts.
Rules and check: skill `requirements-authoring` (section "Folder tree and IDs").

| Number | Path | ID prefix | Content |
|---|---|---|---|
| 01 | `01-general.md` | PRD-01- | Rules for all products, interfaces between products |

## Retired numbers

None.
