# KPI Definition

Pass criteria for the business requirements pull request. One `##` section per KPI. IDs are KPI-001, KPI-002 and so on.
A dashboard is a separate feature and is built only when requested.

## KPI-001 <short name>
- **Business requirement:** BR-001
- **Definition or formula:** <how it is calculated>
- **Unit:** <unit>
- **Data source:** <system, or "not yet available">
- **Baseline:** <current value, or "unknown">
- **Target:** <value>
- **Pass threshold:** <value that counts as success>
- **Measurement window:** <for example 30 days after release>
