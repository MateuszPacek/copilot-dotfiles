# KPI tree

Pass criteria for the business requirements. The tree mirrors `docs/requirements/br/`: the KPIs of `br/02-common/02-finance.md` are in `kpi/02-common/02-finance.md`, with IDs such as `KPI-02-02-001` (template `../templates/kpi-chapter.md`). Every KPI names its BR, and every BR lists its KPIs. The pass thresholds are the gate for the BR pull request.
Rules and check: skill `requirements-authoring`.
