# Technical requirements tree

Organised by system component (for example client, server, admin tool, storage), not by product module. Each TR links to its PRD parent. Same rules as the PRD tree: `01-general.md` at the root, `NN-name` folders and files, `_index.md` for interfaces between a folder's components, fixed numbers, IDs such as `TR-02-01-003`.
The component tree is decided when the TR layer is drafted.
Rules and check: skill `requirements-authoring` (section "Folder tree and IDs").
