# Personal Copilot customizations

This repository is the personal `~/.copilot` folder. For installation and
Codespaces setup, see [codespaces-guide.md](codespaces-guide.md). For the
requirements workflow and `/flow`, see [workflow-guide.md](workflow-guide.md)
and [workflows/software-workflow.md](workflows/software-workflow.md).

The root `install.sh` installs personal Copilot customizations into a new
Codespace. The optional Claude Code route uses
`workflow-kit/install-claude.sh`. Review changes and follow company policy
before publishing this repository.
