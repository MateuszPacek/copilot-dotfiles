## Workflow kit
In any repo with a `workflow/` folder, use `/flow` (skill `workflow-manager`) and read `workflow/state.md` first. Ask instead of assuming. Never push to the default branch or merge.
This setup is billed through the Claude Pro subscription only. Never use or ask for an Anthropic API key. If a session warning says an API credential is set, tell the user first.
